# Product UI

Product UI is Xero's proof: real dashboards on laptop, tablet and phone. It answers "what does it actually look like" and suits mid and lower funnel.

## Rules

**PU1 MUST: Show real Xero UI from the kit (white cards on light grey, blue accents); never invent, recolour or crop through key numbers.**
- How to apply: use a `product_ui` catalog asset whole, `fit: contain`, as `hero` or `proof`. Size it so the key numbers and chart are legible at feed size (rarely below ~1/3 of canvas width for a hero).
- Never generate a fake dashboard, never recolour the UI to match the ad palette, and never crop so that a headline number or chart is cut in half.
- A competitor's star-rating or review badge maps to a product UI card (brand proof is product, not reviews).
- Edge cases: a `proof` slot that was text may stay text or become a product UI card; state which.
- Why: the UI is a fixed brand asset; altered UI misrepresents the product.

## What real Xero UI looks like (for checking)
- White card-based layout with light grey borders on a light grey background (#F5F5F5 / #F5F6F7).
- Xero logo top-left on a blue header bar (#13B5EA; #0B5CFF also observed).
- Brand blue (#13B5EA / #0B5CFF) for primary buttons, chart bars and active elements; light blue (#B3E5F9 / #E6F4F9) secondary bars.
- Green (#00A65A) for positive growth, red (#DC2626) for overdue/negative.
- Bold sans for numbers and headings, regular for labels; text #333333/#000000, secondary #666666/#999999.
- Dashboards in 2x2 or 3-column card grids; avatar and bell top-right (observed).

## Placement
- Best on a white template area or flat cyan/sky field; a bleeding bloom behind the device adds brand energy.
- Do not place text over the UI; keep the device clear.
