# Patterning

In the right context, blooms can repeat across a surface as a textural background. It is a strong move, used sparingly.

## Rules

**PT1 MUST: Use bloom patterning only with clear intent (it supports the message); never as decorative filler.**
- How to apply: use a pattern only when it adds meaning (e.g. it reads as abundance, activity, many connected things) or clearly strengthens the composition. If the ad has a hero image, product UI or photo, a pattern behind it usually competes; prefer a single bleeding bloom.
- Reviewer check: a pattern that exists "to fill space" is a failure; flag it and suggest a flat field + one bloom.
- Why: the brand book says patterns "shouldn't be applied arbitrarily or purely for decoration".

**PT2 MUST: A pattern uses at most 3 colours on a navy base, blooms cohesive in form and orientation; no text directly on it.**
- How to apply: navy (#000856) base field; up to three bloom colourways (e.g. blue + lightblue + purple, or a tonal navy-on-navy). All blooms flow the same way (similar angle and rhythm), large and cropped by the edges, not a scattered confetti of small shapes.
- Text: a pattern is busy, so headline and CTA must sit on a white card or flat navy band (TY4), and the logo needs a pill (LG3).
- Counting: the navy base does not count toward the 3; the pattern colours count toward the ad's bloom-colour budget (BL3).
- Edge cases: a tonal pattern (one mid-navy colour on navy) is the calmest option and suits lower-funnel.

## Catalog assets
- No pre-built pattern asset. Build from kind `bloom` (12 shapes x 7 colourways) on a navy `background_colour`, every bloom bleeding off an edge.
